# 连锁挖掘 — 配置说明

默认按 `V + M` 打开配置界面。也可以直接编辑游戏目录下的 `config/veinmine.json`。

## 受保护的工具与连锁忽略方块

两份列表都支持按名称或 ID 搜索、多选和手动添加。进入世界后可以浏览完整列表，已识别的条目会显示游戏内名称和可用的图标。点「仅看已选」查看当前选择。在主菜单也能添加 ID 和管理已选项。

手动添加时可以填 `minecraft:diamond_pickaxe` 这样的完整 ID。输入 `stone` 也可以，游戏会补成 `minecraft:stone`。找不到对应物品或方块的 ID 会保留，取消勾选即可移除。

点「完成」返回配置界面，再点「保存并关闭」写入配置文件。

## 多人游戏

在支持同步的服务器上，进服或保存配置时会同步工具保护设置和忽略方块列表。搜索模式、范围和上限由服主设置。

局域网房主可以在「高级选项」里切换「多人规则」。访客同步前使用房主的设置。专用服务器在 `config/veinmine.json` 中设置 `serverRuleMode`。

| `serverRuleMode` | 使用哪套设置 |
|---|---|
| `CLIENT`（默认） | 使用玩家的设置。服务器还没收到玩家的设置时，使用服务器的设置。 |
| `OVERRIDE` | 所有玩家都使用服务器的设置。 |
| `APPEND` | 合并玩家和服务器的忽略方块列表。双方开启的工具保护都生效。同一把工具有两个耐久要求时，取较高的值。 |

比如服务器在 `APPEND` 模式下开启了工具保护，并要求铁镐至少剩 20 点耐久。玩家即使关闭了自己的工具保护，服务器也会保护铁镐。服务器规则只在这台服务器上生效，不会写进玩家的配置文件。

要追加规则，在 `config/veinmine.json` 中把 `serverRuleMode` 设为 `APPEND`。

```json
{
  "serverRuleMode": "APPEND"
}
```

服务器在同一份文件里设置要保护的工具和要忽略的方块。改完运行 `/veinmine reload` 加载设置。

## 通用设置

| 键名 | 类型 | 作用范围 | 默认值 | 说明 |
|---|---|---|---|---|
| `searchRadius` | 整数 | 服务端 | `1` | 范围搜索时，从第一块向各方向检查的格数。半径为 `1` 时检查 `3 × 3 × 3` 的范围。 |
| `BFSLimit` | 整数 | 服务端 | `50` | 连锁搜索最多可以找到的方块数。 |
| `ignoredBlocks` | 字符串列表 | 玩家设置 | `[]` | 从列表中的方块开始挖时，改用范围搜索。如果关闭了范围搜索，就不触发连锁。 |
| `useBFS` | 布尔 | 服务端 | `true` | 启用连锁搜索。关闭后直接尝试范围搜索。 |
| `useRadiusSearch` | 布尔 | 服务端 | `true` | 启用范围搜索。 |
| `useRadiusSearchWhenReachBFSLimit` | 布尔 | 服务端 | `true` | 超过连锁搜索上限时尝试改用范围搜索。需要启用范围搜索。 |
| `highlightBlocksMessage` | 布尔 | 客户端 | `true` | 提示搜索找到的目标方块数量。 |

服务端始终跳过以普通空气、洞穴空气或虚空空气为起点的搜索。如果设定普通铁矿石和深板岩铁矿石可以连锁，忽略其中一种也会影响另一种。设定为可以互相连锁的染色方块同理。

## 搜索逻辑

| 键名 | 类型 | 作用范围 | 默认值 | 说明 |
|---|---|---|---|---|
| `distinguishCropMaturity` | 布尔 | 服务端 | `false` | 开启后，`minecraft:crops` 标签中的成熟作物和未成熟作物分开匹配。 |
| `distinguishDyedBlockColors` | 布尔 | 服务端 | `true` | 区分同一系列染色方块的颜色。关闭后，同一系列的不同颜色可以连锁。 |
| `distinguishDeepslateOres` | 布尔 | 服务端 | `false` | 区分同种矿石的普通和深板岩变体。关闭后，两种变体可以连锁。 |
| `bridgeOneBlockGap` | 布尔 | 服务端 | `false` | 可以沿同一方向跳过一个非目标方块继续搜索。跳过的方块不会被破坏。此项位于「高级选项」。 |

## 工具和保护

| 键名 | 类型 | 作用范围 | 默认值 | 说明 |
|---|---|---|---|---|
| `protectTools` | 布尔 | 玩家设置 | `true` | 启用工具保护。耐久不足时取消后续连锁挖掘，手动挖掉的第一块照常破坏。 |
| `protectedTools` | 字符串列表 | 玩家设置 | `[]` | 手动添加的受保护工具，如 `minecraft:iron_pickaxe`。 |
| `protectAllDefaultValuableTools` | 布尔 | 玩家设置 | `true` | 启用工具保护时，自动保护金、钻石和下界合金的镐、斧、锹、剑和锄。 |
| `durabilityThreshold` | 整数 | 玩家设置 | `10` | 连锁挖完后，受保护的工具至少要剩多少耐久。界面可设为 `1` 至 `256`。 |

## 高亮设置

| 键名 | 类型 | 作用范围 | 默认值 | 说明 |
|---|---|---|---|---|
| `enableHighlights` | 布尔 | 客户端 | `true` | 显示连锁目标的高亮边框。 |
| `red` | 整数 0–255 | 客户端 | `255` | 高亮颜色的红色分量。 |
| `green` | 整数 0–255 | 客户端 | `255` | 高亮颜色的绿色分量。 |
| `blue` | 整数 0–255 | 客户端 | `255` | 高亮颜色的蓝色分量。 |
| `alpha` | 整数 0–255 | 客户端 | `255` | 高亮的不透明度，界面中显示为百分比。 |

## 按键与绑定

| 键名 | 类型 | 作用范围 | 默认值 | 说明 |
|---|---|---|---|---|
